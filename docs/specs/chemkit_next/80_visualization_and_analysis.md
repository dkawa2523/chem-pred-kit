# Visualization & Analysis（ChemKit Next）

## 必須（P0）
- parity plot（y_true vs y_pred）
- residual plot（residual vs y_true / vs feature）
- metric table（split別、タスク別）

## 推奨（P1）
- embedding visualization（UMAP/t-SNE）
- error slicing（元素組成、分子サイズ、RingCount 等）

## optional（P2）
- substructure attribution（token/atom寄与）
- 3D attention 可視化（モデル依存）
